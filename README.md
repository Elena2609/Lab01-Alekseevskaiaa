## Контрольные вопросы

1. Почему программа может узнать имя компьютера, хотя вы не писали его в коде?

Потому что имя компьютера хранится в операционной системе. Когда программа выполняется, она через .NET (класс Environment) обращается к ОС с запросом: "как называется этот компьютер?". ОС возвращает текущее значение из настроек. То есть имя берется не из кода, а из ОС и сведения о компьютере. 

2. Какую роль играет операционная система, когда программа запрашивает у неё сведения?

ОС является посредником между программой и оборудованием.

3. Что означает «64-битнаяОС»?

Это означает, что операционная сисетма использует 64-битную архитектуру: она оперирует адресами и способна работать с гораздо большим адресным пространством, чем 32-битная.

4. Что показывает Environment.ProcessorCount и обязательно ли это число совпадает с числом физических ядер?

Показывает количество логический процессоров, которые видит операционная система. Не обязательно должно быть равно числу физических ядер процессора.

5. Чем память процесса (WorkingSet) отличается от всей оперативной памяти компьютера?

WorkingSet - это объем  физической памяти, который в данный момент используется конкретным процессором. Вся оперативная память компьютера - это общий ресурс, которым пользуются все запущенные процессы, сама ОС и системные службы.

6. Почему одна и та же программа безизменений в коде может показать разные результаты на разных компьютерах?

Потому что программа не хранит эти значения в себе, а берет их от ОС того компьютера, на котором запущена. у разных компьютеров разные имена, версии ОС, число логических операторов, поэтому результаты отличаются.

## Дополнительно задание. Мини-монитор системы

### Что делает программа

Выводит сведения о компьютере (имя, пользователь, ОС, разрядность, число логических процессоров) и о текущем процессоре (PID, объем памяти через класс Process).
  
### Что нового я узнала о классе Process

Process.GetCurrentProcess() возвращает объект текущего процесса. Через него можно получить PID и WorkingSet(память) - то же, что дает Environment, но через объектную модель.

Значение может отличаться, потому что Windoms и .NET могут отображать разные показатели памяти. Процесс динамичен, поэтому два замера с интервалом дают разные числа.
